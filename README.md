## About

I’m a cybersecurity student focused on ethical hacking, web application security, secure development, networking fundamentals, and practical security review.

My current goal is to build proof that I can understand, test, document, and improve real systems — not just follow tutorials. I’m especially interested in web security, access control, authentication, automation, and turning projects into clear security case studies.

This profile is intentionally privacy-conscious. I keep personal identifiers, exact location, school details, addresses, and direct personal contact information off my public README.

---

## Current Focus

- Web application security: authentication, authorization, access control, XSS, SQLi, CSRF, SSRF, and secure forms
- Ethical hacking practice in legal lab environments only
- Security reviews for real projects: secrets, dependencies, headers, privacy, backups, and deployment risks
- Networking fundamentals: scanning, enumeration, packet inspection, and protocol behaviour
- Automation with Python, Bash, and PowerShell
- Documenting AI-assisted projects honestly and professionally

---

## AI-Assisted Development

I use AI-assisted development tools to speed up implementation, exploration, and documentation.

That does **not** mean I treat generated code as automatically correct or secure. My role is to define requirements, gather and structure information, guide implementation, review generated output, test behaviour, improve documentation, and identify security risks.

My focus is to become the person who can explain, debug, maintain, and secure what gets built — whether the first draft came from me, a framework, a template, or an AI coding assistant.
